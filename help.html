💬 Chat & Writing
💬
AI Chat
Streaming, history, system prompt
1
Set system prompt (optional): "You are a Python expert" or leave blank.
2
Type message → Enter to send (Shift+Enter = new line).
3
AI replies word by word. Click ■ to stop. History auto-saved.
🌐
Translator
30+ languages including all Indian langs
1
Pick source (or Auto-detect) and target language.
2
Paste text → Translate. Click ⇄ to swap and translate back.
✅
Grammar Checker
Diff view, score /100, issue list
1
Pick style: Standard / Formal / Casual / Business.
2
Paste text → Check Grammar → see score, diff view (green=added, red=removed), issues list.
3
Click Copy Fixed to copy corrected version.
🔁
Paraphraser
6 modes, side-by-side view
1
Pick: ✨ Fluency · 👔 Formal · 🎨 Creative · ⚡ Shorten · 📖 Expand · 🔍 Simplify
2
Paste text → Paraphrase. Original left, result right. Copy or download.
📝
Text Summarizer
Bullet, TLDR, Key Facts, Abstract
1
Pick format + length (Short/Medium/Detailed).
2
Paste text → Summarize → Copy or Download.
🎭
Tone Analyzer
Sentiment, formality, emotion bars
1
Paste any text (email, tweet, article, speech).
2
See: sentiment (😊😠😐), formality level, tone % bars, emotion tags, analysis.
Tip: Paste your email before sending to check tone.
📧
Email Writer
8 types, 5 tones, 3 lengths
1
Pick type: Follow-up / Request / Apology / Complaint / Intro / Thank You / Decline / Custom.
2
Fill recipient, your name, context (be specific). Pick tone + length → Write Email.
3
Output includes Subject line + full body. Copy or download.
💡
Idea Generator
8 categories, up to 20 ideas
1
Pick category: General / Business / Content / App / Names / Projects / Marketing / Essay.
2
Enter topic + optional context → pick count (5/10/15/20) → Generate.
📄 Document Tools
📄
Doc Summarizer
PDF, Word, Image, or pasted text
1
Pick tab: PDF / Word / Image / Paste Text. Upload file or paste text.
2
Pick style: Detailed / Bullet Points / Short / Academic → Summarize.
💡 Use Gemini for large PDFs — it auto-detects the best model from your key.
🔄
File Converter
PDF↔Word↔Image↔Text
1
Pick input: 📄 PDF · 📝 Word · 🖼 Image · 📃 Text. Upload file — confirms with ✅.
2
Pick output format (auto-updates based on input type).
3
Click Convert → downloads instantly.
Examples: PDF→Word · PDF→Markdown · Word→PDF · 3 images→PDF · Text→PDF
🔗
Doc Merger & Page Editor
Merge PDFs or remove/replace pages

Mode 1 — Merge:

1
Add 2+ PDFs. Set page range: "1-4", "2,5,8", blank=all.
2
Use ▲▼ to reorder → Merge → combined PDF downloads.

Mode 2 — Remove/Replace:

1
Upload PDF → thumbnails of every page appear.
2
Click pages to exclude (turns red = removed).
3
Optional: upload replacement PDF to insert at any position.
4
Apply → clean PDF downloads.
Example: Doc has pages 1-4 (keep), 5-8 (remove), 9-43 (keep). Upload → click 5,6,7,8 red → Apply → done!
📋
Resume Analyzer
Score /100, ATS keywords, quick wins
1
Enter target job role + experience level.
2
Paste full resume text → Analyze → score, strengths, improvements, missing keywords.
💡 Change the role each time you apply — different job = different keywords.

Pick tone → Generate → Download.
