# ToolKit AI — 26 AI Tools in One Place

> Free · Private · No signup · Bring your own API key

## Tools
Chat · Translate · Grammar · Paraphrase · Summarize · Tone · Email · Ideas · PDF Summarizer · File Converter · Resume · Cover Letter · Flashcards · Code · Essay · Quiz · Image Generator · Data Analyzer · Meeting Notes · Social Media · Recipe · Workout · Travel · Study Planner · Doc Merger · Help Guide

## AI Backends
- **Groq** — free, ultra fast → console.groq.com
- **Gemini** — free, best for large docs, auto-detects best model → aistudio.google.com  
- **Ollama** — 100% local & offline → ollama.com

## Quick Start
1. Open `index.html`
2. Pick AI backend in setup wizard
3. Use any of the 26 tools

## Deploy to Vercel
```bash
git init && git add . && git commit -m "ToolKit AI launch"
git remote add origin https://github.com/YOUR_USER/toolkit-ai.git
git push -u origin main
```
vercel.com → New Project → Import → Deploy
